# Fotos de los reconocimientos

Guarda aquí las fotos o escaneos de los reconocimientos (WebP o JPG, máximo 1600 px de ancho).

Para mostrarlas en la página `paginas/reconocimientos.html`, añade dentro de cada `<li class="award">` un
`<figure class="media r-3x2">` con la imagen y su texto alternativo.
